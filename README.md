# 예비군 평가 · 설문 시스템

NFC 카드를 휴대폰에 태그하면 부대 전용 페이지가 열리고, 거기서 **평가**와 **설문**
구글폼으로 연결됩니다. 카메라 차단 상태에서도 QR 없이 동작합니다.

```
 NFC 카드 태그
      │
      ▼
 부대 전용 페이지  ──▶ [평가 응시]  ──▶ 구글폼(퀴즈) ──▶ 응답 스프레드시트
 (index.html)      └─▶ [설문 참여]  ──▶ 구글폼(무기명) ─▶ 구글폼 요약 그래프
      │                                                      │
      ▼                                                      ▼
 관리자 페이지 (admin.html) ◀── Apps Script ──── 조별 평균 · 미제출자 집계
   · 평가 / 설문 열기·닫기        (Code.gs)
   · 조별 순위, 우수 조
```

## 폴더 구성

| 경로 | 설명 |
|---|---|
| `docs/index.html` | 예비군이 보는 첫 화면 (평가 · 설문 배너) |
| `docs/admin.html` | 교관용 관리자 화면 (현황판 · 개폐 버튼) |
| `docs/config.js` | **부대별 설정 파일 — 여기만 수정** |
| `docs/styles.css`, `common.js`, `landing.js`, `admin.js` | 화면 구성 파일 (수정 불필요) |
| `apps-script/Code.gs` | 구글 시트에 붙여넣는 백엔드 코드 |

# 설치 (1회, 약 30분)

## 1단계 · 구글폼 2개 만들기

### 평가용 폼
1. [forms.google.com](https://forms.google.com) 에서 새 폼 생성 → 제목 예: `2026년 예비군 정신전력 평가`
2. **설정 → 퀴즈로 만들기** 켜기 (자동 채점되어 `점수` 열이 생깁니다)
3. **첫 번째 질문**을 아래와 같이 만듭니다.
   - 질문: `본인 번호 (조-번)`
   - 유형: **단답형**
   - **필수** 켜기
   - 설명: `예) 3조 7번 → 3-7`
   - (권장) 응답 확인 → **정규식 → 패턴 일치** → `^\s*\d{1,3}\s*-\s*\d{1,3}\s*$`
     · 오류 문구: `조-번 형식으로 입력하십시오. 예: 3-7`
     → 이렇게 하면 번호를 잘못 써서 조 점수에 반영되지 않는 사고를 막을 수 있습니다.
4. 이후 평가 문항들을 추가하고, 각 문항의 **답안 및 배점**을 지정합니다.
5. 설정에서 **응답 횟수 1회로 제한**은 **끄는 것을 권장**합니다.
   (구글 로그인을 강제하게 되어 예비군들이 막힙니다. 중복 제출은 시스템이
   자동으로 *마지막 제출만* 인정하므로 문제되지 않습니다.)

### 설문용 폼
1. 새 폼 생성 → 제목 예: `2026년 예비군 훈련 만족도 설문`
2. **이메일 수집 끄기**, 번호 질문 **없음** (무기명)
3. 실시간 결과는 폼의 **응답 → 요약** 탭에서 바로 확인됩니다.
   (원하면 `응답 → 점 세 개 → 응답 요약 공개`로 링크를 만들 수 있습니다)

## 2단계 · 응답 스프레드시트 연결

**평가용 폼**에서 `응답 → 스프레드시트에 연결 → 새 스프레드시트 만들기`.
생성된 시트 이름을 예: `예비군 평가 관리`.

> 설문 폼은 연결하지 않아도 됩니다. 집계가 필요 없습니다.

## 3단계 · Apps Script 설치

1. 방금 만든 스프레드시트에서 **확장 프로그램 → Apps Script**
2. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣고 저장
3. 상단 함수 목록에서 **`setup`** 선택 → **실행** → 권한 승인
   (⚠ "이 앱은 확인되지 않았습니다" 화면이 나오면
   `고급 → 안전하지 않은 페이지로 이동` 을 누릅니다. 본인이 만든 스크립트입니다.)
4. 스프레드시트에 **`설정`** 탭이 생깁니다. 아래 값을 채웁니다.

| 항목 | 예시 값 | 설명 |
|---|---|---|
| 부대명 | `제○○보병사단 예비군훈련대` | 첫 화면 제목 |
| 관리자PIN | `74125` | **반드시 변경.** 교관들끼리 공유 |
| 평가폼_편집링크 | `https://docs.google.com/forms/d/1AbC.../edit` | 평가 폼을 **편집 상태로** 열었을 때 주소창의 주소 |
| 설문폼_편집링크 | `https://docs.google.com/forms/d/2XyZ.../edit` | 설문 폼의 편집 주소 |
| 조개수 | `10` | 전체 조 수 (m) |
| 조별인원 | `10` | 조당 인원 (n) |
| 평가개방 | `아니오` | 관리자 화면에서 바꾸므로 그대로 |
| 설문개방 | `아니오` | 동일 |
| 점수계산 | `합계` | 점수열이 여러 개일 때 `합계` 또는 `평균` |

> **편집링크 vs 응시링크**: 주소에 `/d/e/`가 들어간 것은 *응시용* 링크입니다.
> 설정 시트에는 `/d/<아이디>/edit` 형태의 **편집 링크**를 넣어야 열기·닫기가 동작합니다.
> 응시링크는 자동으로 채워집니다.

5. 조 인원이 조마다 다르면 **`명단`** 이라는 탭을 만들고 A1에 `번호`,
   A2부터 `1-1`, `1-2`, … 를 모두 적습니다. 명단 탭이 있으면 그것이 우선합니다.

6. **배포**
   - 우측 상단 **배포 → 새 배포 → 유형 선택(톱니) → 웹 앱**
   - 설명: `예비군 평가 v1`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 중요
   - 배포 → 받은 **웹 앱 URL** (`https://script.google.com/macros/s/..../exec`) 복사

## 4단계 · 웹페이지 올리기 (GitHub Pages, 무료)

1. `docs/config.js` 를 열어 두 곳을 채웁니다.
   ```js
   unitName: "제○○보병사단 예비군훈련대",
   apiUrl:   "https://script.google.com/macros/s/..../exec",
   ```
   (평가·설문 링크는 설정 시트에서 자동으로 가져오므로 비워 둡니다.)

2. [github.com](https://github.com) 에서 새 저장소 생성 (예: `reserve`, **Public**)
3. 이 폴더의 파일들을 업로드 (`Add file → Upload files` 로 폴더째 끌어다 놓기)
4. 저장소 **Settings → Pages** → Source: `Deploy from a branch`,
   Branch: `main` / 폴더: **`/docs`** → Save
5. 1~2분 뒤 주소가 나옵니다: `https://<아이디>.github.io/reserve/`
   → 이 주소가 **NFC 카드에 넣을 주소**입니다. 휴대폰으로 먼저 열어 확인하십시오.

> 사내망·보안 정책상 GitHub 가 어렵다면 Cloudflare Pages, Netlify Drop 등
> 정적 호스팅 어디든 `docs` 폴더만 올리면 동일하게 동작합니다.

## 5단계 · NFC 카드 제작

### 카드 선택 — 여기서 실패하는 경우가 가장 많습니다
- **필요한 것은 NFC (13.56MHz) 카드**이며, 칩은 **NTAG213 / NTAG215 / NTAG216** 이어야 합니다.
- **Mifare Classic 카드는 아이폰에서 읽히지 않습니다.** 사무실에 흔한 출입증
  계열이 대부분 Mifare Classic 이므로, 반드시 `NTAG` 로 명시된 카드를 구매하십시오.
- 용량: NTAG213(144바이트)로도 위 주소는 충분합니다. 주소가 길면 NTAG215/216.
- 금속 표면(철제 책상, 캐비닛)에 붙이면 인식이 안 됩니다. 카드 형태로 배부하십시오.

### 기록 방법
1. 휴대폰에 **NFC Tools** (또는 NXP TagWriter) 설치
2. `쓰기 → 레코드 추가 → **URL/URI**` → 4단계에서 받은 주소 입력
3. `쓰기` 를 누르고 카드를 태그 → 여러 장을 연속으로 쓸 수 있습니다
4. 배포 전 **다른 휴대폰(아이폰/안드로이드 각 1대)으로 반드시 테스트**
5. 주소가 확정된 뒤에만 앱의 **잠금(Lock)** 기능을 사용하십시오.
   잠그면 **되돌릴 수 없습니다.** 처음 몇 장은 잠그지 않고 운용을 권장합니다.

### 예비군 안내 문구 (카드 뒷면 인쇄 권장)
```
휴대폰 뒷면 윗부분에 카드를 대면 평가·설문 화면이 열립니다.
열리지 않으면: 설정에서 NFC 켜기 (아이폰은 화면만 켜면 됩니다)
그래도 안 되면 주소 직접 입력: <위 4단계 주소>
```
- 아이폰 XS 이상: 화면이 켜져 있으면 자동 인식됩니다.
- 아이폰 7 ~ X: 제어센터에 **NFC 태그 리더**를 추가해 실행해야 합니다.
- 안드로이드: `설정 → 연결 → NFC` 켜기.

# 훈련 당일 운영 절차

1. 교관 휴대폰/PC에서 `https://<주소>/admin.html` 접속 → **PIN 로그인**
2. 평가 시간 전에는 **평가: 마감됨** 상태를 유지합니다.
   → 카드를 태그해도 평가 배너가 눌리지 않고, 폼 주소를 직접 알아도 제출이 거부됩니다.
3. 평가 시작 → **[열기]** 클릭
4. 진행 중 현황판을 보며 관리합니다.
   - **조별 순위**: 평균 점수 내림차순, 1위에 🥇 (우수 조)
   - 제출이 덜 된 조는 **미완** 표시
   - **조별 제출 현황**: `3-7` 칩이 초록색이면 제출 완료, 회색이면 미제출
     → 미제출자 번호를 그대로 호명하면 됩니다
   - 빨간색 칩 `2-10 ?` = 명단에 없는 번호 (번호 오기 의심)
   - **번호 확인 필요** 표: 번호 형식이 틀려 조에 반영되지 않은 응답
5. 전원 제출 확인 후 **[닫기]** → 그 시점의 순위가 확정됩니다
6. **CSV 저장** 으로 개인별 점수와 조별 평균을 내려받아 결과 보고에 사용합니다
7. 설문도 동일하게 **[열기] → [닫기]**. 실시간 결과는 구글폼 `응답 → 요약` 탭에서 확인합니다

> 구글 시트에서 직접 운영해도 됩니다. 시트 상단 **`예비군 평가`** 메뉴에
> 열기/닫기와 `현황 요약 보기` 가 있습니다.

# 점수 집계 규칙

- **번호 인식**: `3-7`, `3 - 7`, `3조 7번` 모두 인식합니다. 인식 실패 시
  *번호 확인 필요* 목록에 따로 표시됩니다.
- **중복 제출**: 같은 번호가 여러 번 제출하면 **마지막 제출만** 인정합니다.
- **점수 열**: 퀴즈형 폼의 `점수` 열을 자동으로 사용합니다.
  퀴즈가 아니라 척도형(1~5점) 문항이라면 숫자 열들을 자동으로 찾아
  `점수계산`(합계/평균)에 따라 개인 점수를 냅니다.
  자동 인식이 어긋나면 설정 시트의 `점수열` 에 열 제목을 쉼표로 지정하십시오. (예: `문항1, 문항2, 문항3`)
- **조 평균**: 그 조에서 **제출한 인원의 평균**입니다. 미제출자는 0점으로 계산되지
  **않습니다.** 따라서 공정한 비교를 위해 **전원 제출을 확인한 뒤 마감**하십시오.
  (미제출이 있는 조는 순위표에 `미완` 으로 표시됩니다.)

# 문제 해결

| 증상 | 조치 |
|---|---|
| 카드를 태그해도 반응 없음 | NFC 꺼짐 / Mifare Classic 카드 / 금속면 부착 / 태그 위치(아이폰은 상단) 확인 |
| 첫 화면이 "확인 불가" | `config.js` 의 `apiUrl` 오타, 또는 배포 시 **액세스: 모든 사용자** 미설정 |
| 배너가 계속 "준비 중" | 설정 시트의 `평가폼_편집링크` 가 비었거나 `/d/e/` 응시링크가 들어간 경우 |
| 로그인에서 "PIN이 올바르지 않습니다" | 설정 시트 `관리자PIN` 값 확인 (앞뒤 공백 주의) |
| 열기/닫기는 되는데 폼이 안 닫힘 | `평가폼_편집링크` 가 **편집 링크(.../edit)** 인지 확인 |
| 점수가 전부 `-` | 퀴즈 배점 미지정, 또는 `점수열` 을 수동 지정 |
| 조가 안 보임 | `조개수`/`조별인원` 값 확인, 또는 `명단` 탭 확인 |
| 코드를 고친 뒤 반영이 안 됨 | Apps Script 에서 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** |

# 보안상 알아둘 점

- 관리자 화면은 **PIN 한 개로만** 보호됩니다. 내부망 교육용 수준의 보호이며,
  군사 비밀이나 개인정보를 이 시스템에 넣어서는 안 됩니다.
- 번호(`m-n`)만 수집하므로 성명·군번 등 개인정보는 저장되지 않습니다.
  **평가 폼에 성명·군번 질문을 추가하지 마십시오.**
- 설문은 무기명 원칙을 지키기 위해 폼의 **이메일 수집을 반드시 끄십시오.**
- 페이지 주소를 아는 사람은 누구나 첫 화면을 볼 수 있습니다(검색엔진 노출은
  차단해 두었습니다). 민감 내용은 게시하지 마십시오.
- 응답 스프레드시트는 교관 외에 공유하지 마십시오. PIN이 그 시트에 들어 있습니다.
- 대외 공개·부대 정식 도입 전에는 부대 보안담당자의 검토를 받으십시오.
